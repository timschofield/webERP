Currencies Maintenance

Defines the currencies available. Each customer and supplier must be defined as transacting in one of the currencies defined here.

Any number of currencies can be defined in webERP. Every currency that is transacted with either in sales (AR) or purchasing (AP) needs to be defined in the system. To define currencies go to the Setup tab -> General -> Currency Maintenance. Only a few fields are required to be completed for each currency defined:

  • Currency. The ISO 4217 code for the currency - this is the international standard 3 character code that is used worldwide to represent the currency. If the code entered exists then it is possible for webERP to retrieve exchange rates from either the European Central Bank or Google, if there is no rate maintained for the currency at the ECB. webERP is capable of updating exchange rates daily from the ECB if set to do so under Setup->Configuration ->Auto Update Exchange Rates Daily. If this is set to yes, then when the first user logs in for the day the exchange rates are updated automatically. If it is set to no then exchange rates will only be updated if the user does so manually.
  • Country. The country of the currency can be entered
  • Hundredths Name. The name of 100th of a single unit of the currency can be entered. e.g. pence for GBP or cents for USD
  • Decimal Places to Display.
  • Exchange Rate. The rate. This must be the number of the local currency that can be purchased with one of this currency.
  • Show in webSHOP.

A utility is also provided which can produce a graph of the movement of any of the defined currencies against the functional currency

Form Designer

Customizes the form layout without requiring the use of scripting or technical development.

All measurements are in PostScript points (72 points = 25,4 mm).

All coordinates are measured from the lower left corner of the sheet to the top left corner of the element.

The form elements are:

  • Image. Its atributes are x, y, width and height.
  • SimpleText. Its atributes are x and y.
  • MultiLineText. Its atributes are x, y, width and height.
  • Rectangle. Its atributes are x, y, width and height.
  • CurvedRectangle. Its atributes are x, y, width, height and radius.
  • Line. Its atributes are start x co-ordinate, start y co-ordinate, end x co-ordinate, and end y co-ordinate.

Menu Editor

The Menu Editor allows an administrator to customise the navigation menus that appear for each security role and module. Changes take effect immediately for all users assigned to the affected role.

Navigating to the Menu Editor

Go to Setup → General → Menu Editor. Select a Security Role from the first drop-down and then a Module from the second drop-down, then click Select to load the menu items for that role/module combination.

Adding a New Menu Item

Use the Add New Menu Item form at the bottom of the page:

  • Section — Choose an existing section from the drop-down, or type a new section name into the text box to create a new section.
  • Caption — The label that will appear in the menu.
  • URL — The script name or path the menu item links to (e.g. Customers.php).
  • Position — The sequence number within the section where the item will be inserted. Leave blank to append at the end.

Click Add Item to save.

Editing a Menu Item

Click the Edit link on any row to load that item into the edit form. Adjust the Section, Caption, or URL as required and click Update Item to save the changes.

Reordering Menu Items

Use the up () and down () arrow icons on each row to move an item one position within its section. The page reloads after each move so the new order is immediately visible.

Deleting a Menu Item

Click the Delete link on the item row. You will be asked to confirm before the item is permanently removed.

Renaming a Section

Each section heading has a Rename Section form. Enter the new section name and click Rename. All items in the section are moved to the new name in a single operation.

Deleting an Entire Section

Click Delete Section next to a section heading to remove all menu items in that section at once. This action cannot be undone.

Copying Menu Items from Another Role/Module

The Copy Menu Items panel at the top of the page lets you bulk-copy all menu items from a source role and module into the currently selected role and module. This is useful when setting up a new role that is similar to an existing one. Existing items in the target role/module are not removed; the copied items are appended.
