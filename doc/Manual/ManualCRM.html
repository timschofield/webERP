Customer Relationship Management (CRM)

Overview

The webERP CRM module provides a complete sales pipeline from first contact through to a closed customer. It shares the same login, permissions and data as the rest of webERP, so a converted lead automatically becomes an accounts-receivable customer with no re-keying of information.

The module is built around four core concepts:

  • Leads — people or companies that have expressed interest but are not yet customers.
  • Opportunities — specific potential deals linked to a lead or existing customer, progressed through a defined pipeline.
  • Activities — every interaction in the sales process: calls, meetings, emails, tasks and notes, each logged against a lead, customer or opportunity.
  • Pipeline — a visual board showing all open opportunities grouped by stage, with weighted forecast values.

The CRM section of the menu is organised as follows:

  • Transactions — My Activities, Log Activity, Compose Email.
  • Leads & Opportunities — Leads, Pipeline, Opportunities, Forecast.
  • Reports — Lead Report, Opportunity Report, Activity Report, Customer Health.
  • Maintenance — Activity Types, Lead Sources, Industries, Pipeline Stages, Email Templates.

Getting Started — Initial Setup

Before salespeople begin using the CRM, an administrator should complete the five setup steps below. All maintenance pages are under CRM → Maintenance.

Step 1 — Define Lead Sources

Lead sources record how a prospect first heard about the business. They appear on the lead entry form and in lead analysis reports. Navigate to CRM → Maintenance → Lead Sources and add each channel used (for example: Web Enquiry, Referral, Trade Show). Default sources are pre-loaded — delete or rename any that do not apply. A source cannot be deleted once any lead references it; deactivate it instead to remove it from future entry forms while preserving history.

Step 2 — Define Industries

Industries provide a controlled reference list for the customer Industry field in Customer Maintenance. Navigate to CRM → Maintenance → Industries and add each industry your business reports against (for example: Manufacturing, Retail, Healthcare, Professional Services). Industries can be deactivated to remove them from future customer entry while preserving historical data.

Step 3 — Configure the Sales Pipeline

Pipeline stages define the journey from first contact to close. Navigate to CRM → Maintenance → Pipeline Stages. Each stage has the following fields:

  • Stage Name — displayed on entry forms and the pipeline board.
  • Probability — default probability percentage loaded when this stage is selected on an opportunity.
  • Sequence — display order; a lower number appears further left on the pipeline board.
  • Active — inactive stages are hidden from entry forms without losing history.
  • Closed — marks this as a terminal stage; the probability and outcome are set automatically when a closed stage is chosen.
  • Closed Outcome — must be set to won or lost for any stage marked as Closed.

The default stages are: Prospecting (10%), Qualification (20%), Needs Analysis (40%), Value Proposition (60%), Proposal/Quote (75%), Negotiation (90%), Closed Won (100%), Closed Lost (0%). Edit these to match the actual sales process.

Step 4 — Define Activity Types

Activity types categorise every interaction in the log. Navigate to CRM → Maintenance → Activity Types. Each type has a short code, a display name, an optional icon class (CSS class for theme icon support), and an active flag. Default types are: Note, Phone Call, Email, Meeting, Task, Demo.

An activity type cannot be deleted if any log entries reference it — deactivate it to remove it from future entry without losing history.

Step 5 — Create Email Templates

Templates allow salespeople to send consistent emails without rewriting them each time. Navigate to CRM → Maintenance → Email Templates and click New Template. Enter an internal name, subject and body text. The subject and body support the following merge fields that are resolved at send time:

  • {CustomerName} — name of the customer or lead.
  • {SalesmanName} — name of the assigned salesperson.
  • {CompanyName} — the business name from system settings.
  • {Date} — today’s date.

Templates with duplicate names are rejected. Deactivate a template rather than deleting it once it has been used, so activity log references remain intact.

Lead Management

Leads are prospective customers who have not yet been converted to accounts-receivable records. The lead lifecycle runs through the following statuses: New, Contacted, Qualified, Unqualified, Converted.

Creating a New Lead

Navigate to CRM → Leads & Opportunities → Leads and click New Lead. The form has the following fields:

  • First Name / Last Name — the contact person at the prospect organisation.
  • Company — the organisation name; leave blank for an individual.
  • Job Title — optional, useful for segmentation and correspondence.
  • Email / Phone / Mobile — contact details for the lead.
  • Website — the prospect’s website address.
  • Industry — free-text sector description.
  • Lead Source — how the prospect was acquired; select from the maintenance reference list.
  • Status — start with New and update as the lead progresses.
  • Assigned To — the salesperson responsible for follow-up.
  • Estimated Value — expected deal size in the selected currency.
  • Notes — free-text background information about the lead.

Searching and Filtering Leads

The Leads list shows all leads matching the current filter. Available filter options are:

  • Keywords — partial match against first name, last name and company name.
  • Status — restrict to a particular lifecycle stage.
  • Assigned To — show only a specific salesperson’s leads.
  • Lead Source — show leads from one acquisition channel.

Filter selections are saved in the session and persist when returning to the page. Clear them by selecting the blank option in each filter and clicking Search.

Editing and Viewing a Lead

Click Edit on any lead row to open the entry form and update any field. Advance the Status field as the lead moves through qualification. Click View on any row to open the Lead Inquiry page, which shows all fields plus the full history of activities logged against the lead and any linked opportunities.

Deleting a Lead

Click Delete from the edit screen. Only leads that have not been converted to a customer can be deleted. Converted leads are retained for historical reporting accuracy.

Converting a Lead to a Customer

Once a lead is qualified and ready to become an accounts-receivable customer, navigate to the Leads list and click Convert on the lead row. The Convert Lead to Customer page pre-fills from the lead record. Complete the required customer account fields:

  • Customer Number — auto-assigned if the system is configured for automatic numbering; otherwise enter a unique code of up to ten characters.
  • Currency — the currency in which the customer will be invoiced.
  • Payment Terms — select from the terms defined in Receivables setup.
  • Sales Type — the price list applicable to this customer.
  • Customer Type — customer classification used in reporting.

Click Convert. On a successful conversion:

  • A new customer record is created in the accounts-receivable ledger.
  • The lead status is set to Converted and the new customer number is recorded against the lead.
  • Any open opportunities linked to this lead are automatically re-linked to the new customer account.
  • The page redirects to the new customer’s branches page to complete delivery address and salesperson setup.

The lead record is retained and shows which customer it was converted to. If a second user attempts to convert the same lead simultaneously, the system detects the conflict and prevents a duplicate customer being created.

Opportunity Pipeline

An opportunity is a specific potential deal linked to either a lead or an existing customer. It moves through pipeline stages until it is won or lost.

Creating a New Opportunity

Navigate to CRM → Leads & Opportunities → Opportunities and click New Opportunity. The form requires:

  • Opportunity Name — a short descriptive title for the deal.
  • Customer — link to an existing debtor account, or leave blank if the prospect is still a lead.
  • Lead — link to a lead if the prospect is not yet a customer.
  • Stage — the current pipeline stage; selecting a stage loads its default probability automatically.
  • Probability — override the stage default if additional information warrants a different estimate.
  • Amount — estimated deal value.
  • Currency — currency of the deal.
  • Expected Close — target close date, used in the pipeline board and forecast views.
  • Assigned To — responsible salesperson.
  • Description — background detail, key requirements and context for the deal.

Progressing and Editing an Opportunity

Click Edit on any opportunity row to update it. Move it to a later pipeline stage as the deal progresses; the probability is updated automatically from the stage default but can be overridden. Click View for the full opportunity inquiry page, which shows activity history and any linked quotes or sales orders.

Closing an Opportunity

To mark as Won, select the Closed Won stage (or the equivalent stage configured with outcome won) and save. The outcome is set to won, probability to 100%, and the close timestamp is recorded. To mark as Lost, select the Closed Lost stage, enter the reason in the Lost Notes field, and save. If an already-closed opportunity is later edited (for example to correct notes or reassign it), the original close timestamp is preserved.

Filtering the Opportunities List

The Opportunities list supports filters for outcome (open, won or lost), pipeline stage, assigned salesperson, and expected close date range. Each row shows the weighted value (amount × probability) and a currency total runs across the foot of the page.

Pipeline Board

Navigate to CRM → Leads & Opportunities → Pipeline to see all open opportunities in a kanban-style board, one column per active pipeline stage. Each card shows the opportunity name, linked customer or lead, deal amount and assigned salesperson. Each column totals the value at that stage. An optional salesperson filter at the top restricts the board to a single person’s pipeline. To move an opportunity to a different stage, open it with Edit and change the Stage field.

Sales Forecast

Navigate to CRM → Leads & Opportunities → Forecast to compare weighted pipeline value against actual invoiced sales from the sales analysis ledger. Filter by salesperson, currency and accounting period. Weighted open pipeline value and actual bookings for the same period are shown side by side, giving management a view of likely revenue against what has already been confirmed.

Activity Management

Activities are the record of everything that happens in the sales process: calls made, meetings attended, emails sent, tasks assigned and notes written. Every activity can be linked simultaneously to a customer, a lead, an opportunity and a specific contact.

Logging a Completed Activity

Navigate to CRM → Transactions → Log Activity to record something that has already happened. The form requires:

  • Activity Type — select from the reference list (Call, Meeting, Email, Task, Note, Demo, or custom types configured in maintenance).
  • Subject — a brief one-line description of the activity.
  • Description — full notes on what was discussed, outcomes reached and next steps agreed.
  • Customer / Lead / Opportunity / Contact — link to the relevant entity; at least one link should be selected.
  • Assigned To — the salesperson this activity belongs to.
  • Scheduled Start / End — when the activity took place.
  • Status — set to Completed for a past activity.
  • Outcome — brief result description (for example: meeting held, left voicemail, demo delivered).
  • Follow-up Date — if further action is needed, set a date and the activity will appear in the assignee’s My Activities view when that date arrives.

Scheduling a Future Activity

To schedule a call, meeting or task in advance, use the same Log Activity form, set Status to Planned and enter a future date and time in Scheduled Start. Assign it to the appropriate salesperson. The activity will appear in their My Activities view when the scheduled date arrives.

Filtering the Activities List

Navigate to CRM Activities from the menu to see all activities across the team. Filter options include activity type, assigned salesperson, status (planned, completed or cancelled) and a scheduled date range. Filters persist in the session.

Activity Calendar

Navigate to CRM → Transactions → Calendar for a monthly calendar view of all activities that have a scheduled start date. Use this to review meeting density and plan ahead without scheduling conflicts.

Cancelling an Activity

Open the activity with Edit, change Status to Cancelled and save. Cancelled activities remain in the log for reporting purposes.

My Activities — Daily Work View

Navigate to CRM → Transactions → My Activities to open the salesperson’s daily dashboard. Planned activities are presented in three time buckets:

  • Overdue — planned activities with a scheduled start before today that have not yet been completed.
  • Today — planned activities scheduled for today.
  • Upcoming — planned activities scheduled within the next seven days.

Each activity row has a Complete button. Clicking it marks the activity as completed and records the completion time. Only the salesperson to whom the activity is assigned (or an administrative user) can complete it.

Who sees what on this page:

  • Salespeople (users with a salesperson login) see only activities assigned to themselves.
  • Administrative users (no salesperson login) see unassigned activities, allowing them to review and re-assign outstanding work.

It is recommended that salespeople open My Activities at the start of each working day and work through the overdue and today sections before taking on new tasks.

Email Communication

The CRM email tool allows salespeople to compose and send emails from within webERP using pre-built templates and automatically logs every sent email as a completed activity against the linked lead, customer or opportunity.

Sending a CRM Email

Navigate to CRM → Transactions → Compose Email, or click a Send Email link from a lead or customer page. The recipient address is pre-filled when arriving via such a link. To send an email:

  • Select a Template from the dropdown; the subject and body are loaded with merge fields already resolved for the linked entity.
  • Review and edit the subject and body as needed.
  • Click Send.

On a successful send the email is transmitted via the configured SMTP settings and a completed activity of type Email is automatically logged against the linked lead, customer, opportunity and contact. The compose form then clears ready for the next message.

If the send fails, an error message is displayed and the compose form is preserved so the content can be corrected and the send retried without retyping.

Reports

All CRM reports are under CRM → Reports. Each report page has a filter section at the top; click Run Report to refresh results after adjusting filter values.

Lead Report

Analyses leads across four sections. Filters: date range (lead creation date), salesperson.

  • Leads by Status — count of leads at each status, showing the shape of the lead funnel.
  • Leads by Source — breakdown by acquisition channel; use this to evaluate which sources are most productive.
  • Leads by Salesperson — lead count and total estimated value per salesperson.
  • Conversion Metrics — total leads, number converted, overall conversion rate, and average number of days from creation to conversion.

Opportunity Report

Covers pipeline performance across four sections. Filters: date range, salesperson, stage.

  • Open Pipeline by Stage — opportunity count, total value and weighted value at each active stage.
  • Won vs Lost Analysis — win rate, average deal size, and won and lost totals for the selected period.
  • Average Deal Size by Salesperson — won deals only, showing individual performance against peers.
  • Sales Velocity — average number of days from opportunity creation to close for won deals.

Activity Report

Measures sales team engagement across four sections. Filters: date range, salesperson, activity type. Use this report to ensure salespeople are maintaining the expected level of customer contact.

  • Activities by Type — count per activity type (calls, meetings, emails, etc.) for the period.
  • Activities by Salesperson — total activity volume per person.
  • Status Breakdown — planned versus completed versus cancelled counts.
  • Top Overdue Activities — planned activities past their scheduled start date, for follow-up action.

Customer Health Report

Ranks existing customers using Recency, Frequency and Monetary (RFM) analysis drawn from the sales analysis ledger. It identifies at-risk customers (low recent purchasing activity) and high-value customers to prioritise for retention and upsell. No CRM-specific filters are required; the report covers all active customers.

CRM Dashboard

Navigate to CRM → CRM Dashboard for an at-a-glance management view of pipeline health and recent activity. The dashboard displays four panels:

  • Open Pipeline — total open opportunity value and weighted forecast, grouped by currency.
  • Leads by Status — lead counts at each status stage, showing the shape of the current funnel.
  • Activity Counts — activities completed and planned in the current period.
  • Recent Wins — opportunities closed as Won in the last 30 days with their deal values.

The dashboard is read-only. Use the links within each panel to drill through to the underlying list or report for further detail.

Field and Status Reference

Lead Status Values

  • new — lead has been entered but not yet contacted.
  • contacted — initial contact has been made and a relationship started.
  • qualified — lead has been assessed as a genuine prospect worth pursuing.
  • unqualified — lead is not worth pursuing; retained for reporting.
  • converted — lead has been converted to a customer account.

Opportunity Outcome Values

  • open — deal is still in progress.
  • won — deal was closed successfully.
  • lost — deal was not won.

Activity Status Values

  • planned — activity is scheduled but not yet carried out.
  • completed — activity has been carried out and the outcome recorded.
  • cancelled — activity was cancelled; it remains in the log for reporting.
